# MacDownUp

Нативная библиотека macOS с системными обоями, совместимостью Mac и загрузкой установщиков / IPSW.

Разработчик **laberthouman** — https://github.com/laberthouman.

IPSW доступны внутри окна выбранной macOS: откройте систему и выберите «IPSW по модели». Показываются только прошивки этого поколения.

## Автоматический каталог

`catalog.json` содержит версии macOS, источники установщиков, описание, совместимость и ссылки на обои. Приложение получает JSON при запуске и каждый час, а затем атомарно сохраняет последнюю рабочую копию на Mac. Новое поколение появляется без обновления приложения. Старые системы остаются в каталоге при ошибках сети и отсутствии старых установщиков в Apple Software Update.

GitHub Actions **Update macOS catalog** каждые 6 часов проверяет публичный стабильный каталог Apple. Он добавляет новые поколения, обновляет последние версии и ссылки InstallAssistant.pkg, повышает `revision` и делает commit в `catalog.json`. Файлы обоев новых систем скачиваются из архива 512 Pixels, когда становятся доступны. Бета-сборки пропускаются. Если Apple не публикует точную совместимость в метаданных, новая система показывается с пометкой об уточнении списка; существующие проверенные списки сохраняются.

Для запуска загрузите содержимое этой папки в корень публичного репозитория **laberthouman/MacDownUp**, в ветку **main**, включая `.github/workflows`. Во вкладке **Actions** откройте **Update macOS catalog** и запустите **Run workflow** для первой проверки. Далее задача работает по расписанию. Дополнительные токены и сервер не нужны: используется стандартный GITHUB_TOKEN с разрешением `contents: write`. Ограничения аккаунта или репозитория могут требовать включить Actions и разрешить workflow запись в репозиторий. GitHub может задерживать запуск расписания и отключает неактивные расписания в публичных репозиториях после 60 дней без активности; успешные автоматические commit поддерживают активность.

Raw-каталог: https://raw.githubusercontent.com/laberthouman/MacDownUp/main/catalog.json

## Обновления приложения

`app-update.json` сообщает последнюю версию MacDownUp, номер сборки, требования к macOS, ZIP-ссылку и SHA-256. Приложение проверяет файл автоматически; новую сборку можно скачать и установить из окна «Обновления». ZIP, размер, SHA-256, идентификатор приложения, версия и подпись проверяются до замены. Предыдущая сборка сохраняется рядом с приложением.

Workflow **Release MacDownUp** запускается при публикации стабильного Git-тега, например `v3.1`. Он собирает универсальную `.app`, создаёт GitHub Release с ZIP и автоматически обновляет `app-update.json` в main. Исходники и ресурсы должны находиться в репозитории, как в этой папке. Сборка имеет ad-hoc подпись; для внешнего распространения без предупреждения Gatekeeper нужна подпись Developer ID и notarization.

## Ручная корректировка

Можно редактировать описания, совместимость и источники в `catalog.json`. После изменения повышайте `revision`. Типы источников: `appleImage`, `softwareUpdate`, `appStore`, `archive`, `webPage`. Автоматическое обнаружение сохраняет описания, совместимость и архивные источники существующих поколений.

## Сборка

`./build.sh` — локальная универсальная сборка в `~/Applications/MacDownUp.app`.

`./Tools/verify.sh` — проверки каталога, IPSW, сетевых ошибок, кеша и добавления будущих macOS через JSON. `python3 -m unittest discover -s automation -p 'test_*.py'` — проверки автоматического обнаружения и слияния.

Обои принадлежат Apple и их авторам; источники: https://github.com/kdawson133/MacOS-Wallpaper и https://512pixels.net/projects/default-mac-wallpapers-in-5k/ .
